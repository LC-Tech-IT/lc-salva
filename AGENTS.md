# Reglas y Contexto del Proyecto: LC Salva

## 🔒 Aislamiento Estricto de Proyecto
1. **Contexto Exclusivo**: Este espacio de trabajo corresponde exclusivamente al proyecto **LC Salva** (LC Tech).
2. **Cero Cruces de Proyectos**: Todo requerimiento, análisis, comando o implementación en este repositorio está dirigido 100% y de forma aislada a este proyecto. No referenciar, comparar ni mezclar con otros proyectos externos (como Biker Tracker, Dashboard u otros directorios hermanos).
3. **Foco del Producto**: Pulsera inteligente con ficha médica de emergencia (QR / NFC), perfiles de portadores, panel de administración y landing de producto.
